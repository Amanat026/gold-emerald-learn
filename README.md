# English Core AI Lab

Create a modern, elegant, and fully responsive website for "English Core AI Lab", an educational platform founded and led by Amanat Ullah. 

### Brand & Design Identity:

- Theme: Premium, professional, and trustworthy dark-mode aesthetic.

- Background Color: #0B0C10 (Deep Matte Black) as the base for the entire site.

- Primary Text Color: #C9A66B (Antique Gold) for main headings, brand highlights, and important accent elements.

- Secondary Text Color: #F5E6C7 (Soft Cream/Off-white) for body paragraphs and descriptions to ensure high readability against the dark background.

- UI Accents & Icons: #C9A66B (Gold) for links, icons, and small dividers.

### Call to Action (CTA) Buttons:

- Default State: Background and border color #1A4331 (Dark Emerald Green) with #C9A66B (Antique Gold) text.

- Hover State: Background transitions smoothly to #C9A66B (Gold) with #0B0C10 (Black) text for a striking contrast.

### Key Sections & Features Required:

1. Header / Navigation:

   - Display the brand logo (English Core AI Lab emblem combining green and gold tones).

   - Navigation links: Home, About, Programs, Testimonials, and Contact.

   - A prominent CTA button: "Get Started" or "Join Now".

2. Hero Section:

   - Compelling headline introducing English Core AI Lab.

   - Sub-headline featuring Founder and CEO Amanat Ullah.

   - High-impact CTA buttons styled with the emerald green and gold theme.

3. Core Categories Section (Highlighting three main pillars):

   - a. Kids English: Fun, interactive, and engaging learning modules for children.

   - b. Academic English Grammar (Class Six to Ten): Comprehensive structural grammar, textbook support, and exam preparation.

   - c. Professional English for all: Business communication, spoken fluency, and workplace language skills.

4. About the Founder:

   - A dedicated section introducing Amanat Ullah, CEO & Founder, highlighting the vision behind English Core AI Lab.

5. Footer:

   - Brand information, quick links, contact details, and social media handles, wrapped in the dark matte black aesthetic.
